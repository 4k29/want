# Wishlist

シンプルな欲しいもの・分割払い・サブスク管理。GitHub Pagesで動く静的サイトです。ビルドやAPIキーは不要です。

## できること

- 商品リンクから商品名・円価格の取得を試行し、カテゴリーを仮分類。取得できない場合は手入力。
- カテゴリー・優先順位・状態を編集。カテゴリー絞り込み、価格順・優先順・追加順、上下ボタンによる手動並べ替え。
- 購入予定の総額、支払い中の固定費、すべて購入した場合の月額を別々に表示。
- 分割回数・手数料総額（円）または価格に対する手数料総率（%）から月額を試算。実質年率ではありません。
- 初回支払い月から分割の終了を判定。月の境界は日本時間です。
- 月払い・年払いサブスク。年払いは月額換算。実際の引落月別の請求額とは異なります。
- ブラウザ内保存、JSONバックアップ・復元。データはリポジトリには保存しません。

## 公開先

https://4k29.github.io/want/

既存のGitHub Pages設定（mainブランチ・ルート）で公開します。mainの更新が自動的に反映されます。`.nojekyll`により静的ファイルをそのまま配信します。

サイトのコードとURLは公開されますが、登録する個人データは利用したブラウザ内だけに保存します。ブラウザデータの削除で失われるためバックアップを使ってください。同じブラウザの別タブは変更を反映しますが、別端末とは自動同期しません。

## 商品リンクの取得

「情報を取得」で入力URLを[Microlink](https://microlink.io/docs/api/parameters/data)の公開APIへ送信します。JSON-LDのProduct.offers、または価格と通貨のメタデータを使います。通貨が明示的にJPYの価格だけを入力候補にします。範囲価格や複数構成の価格は確定できない場合があります。取得結果は購入時の価格を保証しません。

Microlinkの制限、販売店のアクセス制限、ページ構造、ネットワーク状態によって取得できないことがあります。価格の定期更新は行いません。手入力は常に利用できます。秘密を含むURL、アカウントページ、注文履歴のURLを送らないでください。

## 検証

Node.js 22以上で `npm test`。依存パッケージはありません。
ローカルでは `python3 -m http.server 8000` をこのフォルダーで実行して表示できます。

月額表示は1円単位に丸めます。内部計算では端数を保持し、分割総額と端数調整額を編集画面に表示します。支払い中の一括払いは今後の月額には含めません。優先度・カテゴリーの変更はアイテムの編集から行えます。
