# Wishlist

欲しいもの・分割払い・サブスクを管理する静的サイト。
公開先: https://4k29.github.io/want/

## 端末間の同期

共通データはmainブランチの `data/wishlist.json` に保存します。ページを開くとGitHub Contents APIから取得します。別端末の変更は「最新を取得」、または2分以上空けてタブに戻ったときに取得します。リアルタイム配信ではありません。

閲覧は認証不要です。追加・編集・削除・並べ替え・バックアップ読み込みを保存するには、サイト上の「GitHub接続」でFine-grained personal access tokenを設定します。Repository accessをwantだけに絞り、Contents: Read and writeを付けてください。接続キーはこのブラウザのlocalStorageに保存し、再読み込み・ブラウザ再起動後も保持します。GitHub APIへの認証にのみ使用し、リポジトリのデータ・バックアップには含めません。「接続を解除」で保存キーを削除し、他の開いているタブにも解除を反映します。無効・期限切れ（401）のキーも削除します。ブラウザが保存を許可しない場合は通知し、そのページを開いている間のみ接続します。別端末では最初に接続キーの設定が必要です。共有端末では使用後に解除してください。ChatGPTのGitHub連携とは別の認証です。

登録内容は公開され、削除・変更前の内容もGitの履歴に残ります。接続時に公開への同意を表示します。初期の共通データは空で、端末内にある旧版のデータは自動送信しません。旧データがある端末では「端末のデータを追加」から移行できます。移行時は同じIDの共通データを優先し、追加に成功した後に旧データの端末バックアップを残します。

保存前に最新版を取得して、別々の項目への変更を統合します。同じ項目への異なる変更、削除と編集、競合する並べ替えは上書きせずエラーを表示します。保存時にはGitHubのファイルSHAで競合を検出します。エラー時に保存済みとは表示しません。編集中の入力はそのまま残ります。通信できない間は前回取得したキャッシュを表示しますが、保存には接続が必要です。

データファイルは900KB以下に制限しています。個人の小規模リスト向けで、大量の頻繁な書き込みには向きません。

## 製品画像

商品情報取得でJSON-LDの製品画像、またはOG画像を入力候補にします。編集画面から画像URLを直接指定することもできます。実体の画像ファイルは保存せずURLを共通データに保存し、各端末が読み込みます。販売店側でURLが変更・拒否されると表示できません。読み込みに失敗した画像はプレースホルダーに置き換えます。端末ファイルのアップロードには対応していません。

「情報を取得」では商品リンクを[Microlink](https://microlink.io/docs/api/parameters/data)へ送ります。商品名・画像・JPYが明示された価格を取得します。価格が取得できない場合は手入力できます。税込価格や選択した容量・構成は登録前に確認してください。

## 計算

- 欲しいものの総額：購入予定の商品価格と手数料。
- 固定費：契約中のサブスクの月額換算と、当月支払い中の分割。
- 購入後の月額：固定費と、購入予定の分割。
- 年払いサブスクは12分の1で表示。実際の引落月の請求額とは異なります。
- 分割は回数・手数料総額または商品価格に対する総率を入力。総率は実質年率ではありません。
- 初回支払い月から終了月を判定。日本時間の月を使用。
- 月額表示は円単位に丸め、内部計算は端数を保持。編集画面で端数調整額を確認できます。

## 公開・検証

既存のGitHub Pages設定（main / ルート）で公開します。`.nojekyll`により静的ファイルをそのまま配信します。

Node.js 22以上で `npm test`。計算・UTF-8の往復・画像URL・端末間の競合・GitHubへのリクエストを検証しています。GitHub APIへの書き込みテストはモックを使い、ユーザーの接続キーは使用していません。

ローカル表示: `python3 -m http.server 8000`

GitHub API仕様: https://docs.github.com/en/rest/repos/contents
