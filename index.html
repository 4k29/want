SAVE TO GITHUB

GitHubに保存

普段のGitHubログインで保存できます。トークンの入力は不要です。

  1. 下のボタンでGitHubを開く。
  2. 4k29のアカウントでSubmit new issue（作成）を押す。
  3. このサイトへ戻る。保存完了は自動で確認され、一覧も自動更新されます。

GitHubの画面を開くだけでは保存されません。別端末で先に更新されていた場合は上書きせず、競合として表示します。

商品・金額・サブスク・メモ・画像URLは、公開リポジトリと保存リクエストの履歴に残ります。

変更内容が長いため、本文をコピーしてGitHubの本文欄に貼り付けてください。
